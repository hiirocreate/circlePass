# リッチメニュー画像について

`menu.png` をこのフォルダに配置してください。

- サイズ: 2500 x 843px (横長タイプ) または 2500 x 1686px (縦長タイプ、2行運用の場合)
- 形式: PNG または JPEG
- `scripts/create-rich-menu.ts` は横長タイプ(2500x843)を3分割する前提で
  ホーム / 会員証 / 順番待ちの3つの領域を設定します。
  デザインもこの3分割(各833px幅)に合わせて作成してください。
- 縦長タイプや分割数を変える場合は `scripts/create-rich-menu.ts` の
  `richMenuBody.size` と `areas` を合わせて変更してください。
